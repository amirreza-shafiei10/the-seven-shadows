# The Seven Shadows

A scroll-driven descent through the seven deadly sins: a cinematic fly-in scrubbed frame by frame on canvas, seven skulls that surface one page at a time, and a full-screen reveal for each sin. Plain HTML, CSS and JavaScript in a single `index.html`, no libraries.

**Live:** https://amirreza-shafiei10.github.io/the-seven-shadows/

## Run locally

```bash
node serve.js
```

Then open http://localhost:5173. Opening `index.html` directly from disk works too, but the browser blocks the video frame cache and skull cut-outs on `file://`, so scrolling is less smooth.
